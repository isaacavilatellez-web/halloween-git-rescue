# The Halloween Commit: Horror at the Server Room

## Presentació i entorn

Pràctica de Git per reconstruir un repositori, treballar amb branques,
resoldre conflictes i recuperar una versió segura del codi.

- Sistema operatiu: macOS.
- Terminal: zsh integrada a Visual Studio Code.
